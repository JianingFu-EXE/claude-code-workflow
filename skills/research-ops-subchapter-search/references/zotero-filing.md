# Zotero Filing

Use this reference during Phase 3.

## Collection Shape

Create the Zotero hierarchy from the approved subchapter structure. Treat each leaf subchapter as a first-class collection.

For every leaf subchapter, create:

- `[Subchapter Name]`
- `[Subchapter Name]/Top Tier`
- `[Subchapter Name]/Mid Tier`
- `[Subchapter Name]/Grey Literature/Reports`

## Dual-Filing Rule

Every accepted source must be filed twice:

1. In the main `[Subchapter Name]` collection for topical browsing.
2. In the matching quality subcollection for quality-based filtering.

Do not replace the second filing with tags alone.

## Naming Guidance

- Reuse the approved subchapter labels exactly unless Zotero naming constraints force a minor cleanup.
- Keep sibling names parallel in style.
- Prefer concise labels that still align with the search log.

## Metadata Hygiene

When the workflow includes notes or tags, keep them lightweight and operational:

- note the chosen quality category
- note the reason the source was kept
- tag with the subchapter ID if a stable numbering system exists

## Dedupe Rule

If a paper belongs in multiple subchapters, keep one canonical bibliographic record and place it in each relevant collection rather than creating duplicate items.

## Delivery Format

Return the planned hierarchy in a tree or indented list that can be created directly in Zotero.
